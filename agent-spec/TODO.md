# Owner TODOs (post-launch changes)

Changes the project owner wants once the main build is done. Each item is added
when the owner mentions it with a `TODO:` prefix. Not yet scheduled. When an
item is picked up, turn it into a proper task file in `tasks/` (with owns,
depends_on, and acceptance criteria) and mark it here with the task ID.

**Every open item is also shown on the admin dashboard (`/admin` › To-dos).** An item is
open while its Task column is empty. When you add item #n, also add a migration that inserts
it into `admin_todos` with the fixed id `7d0d0000-0000-4000-8000-<n padded to 12 digits>`,
`created_by` null and `on conflict (id) do nothing` (see `db/migrations/0007_import_todos.sql`).
`tests/db/todo-import.int.test.ts` fails if an open item has no row. Ticking it done on
`/admin` doesn't change this file; mark the Task column here when it's scheduled.
