## Notes

- `supabase start` verified 2026-10-29 on the project machine: Docker Desktop 29.9.2, Supabase CLI 2.122.0 (`pnpm db:start`). The local stack runs with migrations applied and `pnpm test:int` passes against it.
- Docker Desktop installs its CLI in `~/.docker/bin`, which only `~/.zprofile` adds to `PATH`. Agent shells that don't load it report `docker: command not found` (and `supabase status` fails) even though Docker is running. Use `PATH="$HOME/.docker/bin:$PATH"` before `pnpm db:*` commands.
